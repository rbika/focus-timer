# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-08-15

### Added

- Live countdown icon in the menu bar.
- Light and dark mode support.
- Timer state persists across app restarts.
- Timer window:
  - Timer controls.
  - Predicted completion time.
- Settings window:
  - Option to launch at login.
  - Option to hide the window when the timer starts.
  - Option to pause automatically when your Mac sleeps.
  - Option to show only icon in the menu bar.
  - Configurable completion sounds.
